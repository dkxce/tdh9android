# TDH9RadioBridge · TNC через BLE на Android

[RU](README.md) | [EN](README.en.md) | [Releases](https://github.com/dkxce/tdh9android/releases)    

Мост между рацией **TIDRadio TD-H9** (BLE GATT сервис Odmaster `af00`) и сетью
**TCP/IP** с тремя протоколами. Рация выступает как аппаратный KISS-TNC: телефон
подключается по BLE и обменивается с рацией KISS/AX.25-кадрами, а приложение
поднимает локальные TCP-серверы, к которым подключаются APRS-приложения.

**Версия:** v1.1.0

## Возможности

- **BLE-подключение** к рации как к KISS-TNC (service `0000af00`, write `af01`,
  notify `af02`; запасные UUID `ff02`/`ffe2` и `ff01`/`ffe1`).
- **Три TCP-сервера** (один одновременно, выбор режима):
  - **Binary KISS** — порт 8023 (сырые KISS-фреймы, как последовательный TNC по сети);
  - **AGWPE (Dire Wolf)** — порт 8000 (36-байтные заголовки, для UISS/UI-View32/APRSIS32);
  - **APRS-IS** — порт 14580 (текстовый протокол + проверка passcode).
- **Foreground-сервис**: соединение и серверы работают с выключенным экраном.
- Встроенные кодеры/декодеры **KISS** и **AX.25** (бинарный ⇄ текст).
- Лог RX/TX, список клиентов, настройки (SharedPreferences).

## Требования

- Android Studio (Ladybug 2024.2.1+ рекомендуются).
- JDK 17.
- Устройство Android 8.0+ (API 26).
- Рация TIDRadio TD-H9 или прошивка с APRS BLE-сервисом.

### Минимальные требования к Android-устройству

- **ОС:** Android **8.0 (API 26)** и выше.
- **RAM/CPU:** 1 ГБ ОЗУ и одноядерный CPU (приложение работает и на слабых устройствах).
- **Bluetooth:** обязателен модуль **Bluetooth Low Energy (BLE / Bluetooth 4.0+)**.
- **Включённая служба геолокации (GPS/«Местоположение»)** — обязательна для
  BLE-сканирования на Android <12 (запрет платформы, без неё рация не найдётся).
- **Wi-Fi / LAN** — нужен для подключения внешних APRS-клиентов к TCP-серверам
  (телефон и ПК в одной сети).
- **Разрешения при запуске:** Bluetooth, Геолокация; на Android 13+ — уведомления.
- Опционально: хранилище (для логов/настроек) — не критично, данные хранятся
  локально в памяти приложения.

> **Проверка совместимости:** минимальные спецификации — Android 8.0, BLE 4.0,
> геолокация включена. На устройствах без включённой геолокации сканирование BLE
> работать не будет — включите «Местоположение» в настройках телефона.

## Сборка

1. Откройте папку `android-bridge` в Android Studio («Open»).
2. Дождитесь первого Gradle Sync (скачает Gradle 8.9 и зависимости).
3. Подключите телефон с включённой отладкой по USB.
4. Нажмите **Run** (🔨). На телефоне выдайте разрешения Bluetooth и, при
   запросе, уведомление (Android 13+).

Если Gradle не синхронизируется, обновите версии плагинов в `build.gradle.kts`
и `com.android.application`/`org.jetbrains.kotlin.android` до используемых в вашей
Android Studio.

## Использование

### Быстрый старт: как подключить рацию

1. **Включите Bluetooth и GPS (геолокацию)** на телефоне — BLE-сканирование на
   Android требует включённой службы местоположения.
2. **Включите рацию** TIDRadio TD-H9 и включите на ней режим APRS и Bluetooth
3. В выдайте разрешения **Bluetooth** и **Геолокация** (если ещё не выданы).
4. Откройте приложение **TDH9RadioBridge**, вкладку **«Рация»**, нажмите
   **Сканировать**.
5. Из списка найденных устройств выберите рацию (или **История** → ранее
   подключённую) — нажмите на неё, произойдёт **Connect**.
6. В логе появится `[BLE] Connected <имя> (<адрес>)` и список GATT-сервисов.

### Запуск сервера

1. Перейдите во вкладку **«Сервер»**.
2. Выберите **режим** (Binary KISS / AGW (AGWPE) / APRS-IS) и **порт**.
3. Нажмите **«Запустить сервер»**. Внизу появятся **локальные адреса** вида
   `192.168.1.5:8023` — это адрес для подключения.
4. Подключите APRS-приложение к одному из этих адресов (телефон и клиент —
   в одной сети Wi-Fi).

## Совместимость с APRS-приложениями

| Приложение | Протокол | Порт |
|---|---|---|
| **UISS** | AGWPE TCP/IP | 8000 |
| **UI-View32** | AGWPE TCP/IP | 8000 |
| **APRSIS32** | AGWPE (или Binary KISS) | 8000 / 8023 |
| [**KMZViewer**](https://github.com/dkxce/KMZViewer) | KISS / AGW / APRS-IS | по настройке |
| [**APRSWin**](https://github.com/dkxce/APRSWin) | Binary KISS / AGW | 8023 / 8000 |
| [**APRSAir**](https://github.com/dkxce/APRSAIR) | KISS / AGW / APRS-IS | по настройке |

> Программы, умеющие **AGWPE** — ставьте режим AGW (8000); ожидающие **KISS-TNC**
> по TCP — Binary KISS (8023); сетевые APRS-IS — APRS-IS (14580).

## Замечания

- **Ядро (BLE + KISS + AX.25 + три сервера) полностью перенесено из
  Python-проекта** [dkxce/Tidradio-TD-H9](https://github.com/dkxce/Tidradio-TD-H9/tree/main/TDH9KISS)
- Foreground-service типа `connectedDevice` требует на Android 14+ разрешение
  `FOREGROUND_SERVICE_CONNECTED_DEVICE` (заявлено в манифесте).
